vjuu GitHub

Review for agent handoffs

vjuu [vjuː]: "view", in rally English.

Don't open the file. Your agent already did.

Instead of telling you to "open X and review it", your agent runs vjuu X. A window opens with the markdown, diff or source. You comment on the lines, click Done, and your comments go straight back to the agent.

Install Source on GitHub

Why

Built out of annoyance.

  1. Agents

    "Open X and review it."

    I hated it every time. Now the agent opens the file itself, and my comments go back to it as file:line markdown it can act on.

  2. Diffs

    IDE diff windows are sluggish.

    Especially on a cold start. Having the agent push, open an MR and open it in the browser was even slower. Nothing fast and local had inline comments.

  3. Markdown

    Editors, but no viewer.

    Everything I had installed wanted to edit markdown, and none of it let me comment on a line. I couldn't be arsed to look for a viewer I was pretty sure didn't exist, so I built one.

Nice to haves: it's keyboard first (arrows to move, Enter to comment, Ctrl+Enter when done), and dark mode follows your system out of the box.

How it works

Fast enough to stay in the loop.

After the first window, vjuu keeps a pre-warmed one ready. A markdown file appears in about 15 ms. "Ai biliiv täts priti fääst."

  1. Open

    Anything the agent wrote.

    Markdown, diffs and patches, git diff ranges, any source file, or stdin. Several files stack in one window.

  2. Comment

    On a line or a selection.

    Click a line, or select across lines, paragraphs or diff rows. Keyboard first: arrows to move, Enter to comment, Ctrl+Enter when done.

  3. Return

    Markdown on stdout.

    The agent gets every comment with its file:line and the quoted lines. Each review is also saved, and vjuu last prints it again.

Install

Windows, macOS and Linux.

Uses the system web view: WebView2 on Windows, WKWebView on macOS, WebKitGTK 4.1 on Linux (Debian 12+, Ubuntu 22.04+).

Windows
winget install vjuu
macOS
brew install kimvais/tap/vjuu

Not signed or notarised. Homebrew installs work as is; a binary downloaded by hand needs xattr -d com.apple.quarantine vjuu once.

Debian, Ubuntu
curl -fsSL https://vjuu.it/apt/vjuu.gpg | sudo tee /usr/share/keyrings/vjuu.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/vjuu.gpg] https://vjuu.it/apt stable main" | sudo tee /etc/apt/sources.list.d/vjuu.list
sudo apt update && sudo apt install vjuu
Anything else
cargo install --locked --git https://github.com/kimvais/vjuu

Or a .zip, .tar.gz or .deb from GitHub Releases. Building on Linux needs libwebkit2gtk-4.1-dev and libgtk-3-dev.

Then, for Claude Code and Codex
vjuu setup

Installs the skill that tells your agents to run vjuu instead of asking you to open files. Run it again after an upgrade.
